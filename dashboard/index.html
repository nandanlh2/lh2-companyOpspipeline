Live from HubSpot · Company Ops Data pipeline · rebuilt on a schedule, read-only.
The big number on every stage row is how many deals have ever reached that stage — a deal that has since moved further down still counts at every stage it passed through, so the funnel reads top to bottom. Every conversion badge and both rates are computed from it. Rows tagged note or derived have no stage of their own and are read from note text or inferred.
The muted "N now" beside each row is how many deals are sitting at that stage this moment — the same count as the column header on the HubSpot board, kept so the two can be reconciled at a glance. It never moves with the range picker, because "how many are here" is only ever true now.
Total is all of history. Today / WTD / MTD / Custom count the stages entered in that window, on the IST day they were entered — so "Today" is what actually happened today. The 8-week trend charts always show eight weeks and ignore the picker.
